# Bangla Fake News Detection

This application uses a BERT-based model to detect fake news in the Bangla language.

## How to use

1. Enter the news content in the text box.
2. Click "Submit" to see if the news is Authentic or Fake.

## Model

The model is a Bangla-BERT variant fine-tuned for fake news classification.
